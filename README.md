# ARM Repository Template
Basic repository template with required security workflows

This GitHub repo includes:

1. A drawing schematic of the PUFIN TBS INP sampler from the U.S. DOE ARM User Facility
2. A list for all the parts needed to build PUFIN

Definitions of acronyms:

ARM - Atmospheric Radiation Measurement
DOE - Department of Energy
INP - Ice Nuceating Particle
INS - Ice Nucleation Spectrometer
PUFIN - Profiling of Upper altitudes For Ice Nucleation
TBS - Tethered Balloon System
